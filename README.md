# Синтез метана Сабатье — фронтенд

Одностраничное приложение для просмотра материалов реакции Сабатье
(CO₂ + 4H₂ → CH₄ + 2H₂O). Материал реакции — это услуга системы, то есть
исходное вещество для синтеза метана: водород, углекислый газ, вода, биогаз,
катализатор.

Курс «Разработка Интернет Приложений», МГТУ им. Н. Э. Баумана, ИУ5, осень 2026.

## Запуск

Нужен Node.js 22 или новее — вместе с ним ставится npm.

```bash
npm install      # поставить библиотеки из package.json
npm run dev      # http://localhost:3000
```

| Команда | Что делает |
|---|---|
| `npm install` | ставит все библиотеки в `node_modules` |
| `npm run dev` | сервер разработки с горячей заменой модулей |
| `npm run build` | сборка для развёртывания, результат в `dist` |
| `npm run preview` | локальный просмотр собранной версии |

Бэкенд запускать не нужно: в этой работе его нет, содержимое карточек
берётся из коллекции mock-объектов.

Список зависимостей живёт в `package.json`, точные версии фиксирует
`package-lock.json` — оба файла в репозитории, `node_modules` в `.gitignore`.

Содержимое карточек берётся **только из коллекции mock-объектов**
(`src/modules/mock.ts`), веб-сервис в этой работе не подключается.
Менеджера состояний нет, React Context не используется: состояние живёт
в `useState` страниц и передаётся в компоненты через props.

## Страницы приложения

Приложение состоит из трёх страниц. Макет рассчитан на экран телефона
390 × 693 — формат 9:16. Оба размера заданы явно, поэтому ширина всех трёх
страниц одинакова и не зависит от того, что на них лежит. Содержимое
прокручивается между шапкой с названием системы и закреплённой снизу
навигационной панелью.

### Плитка материалов — `/`

Карточки опубликованных материалов в два столбца.

| Элемент | Что это |
|---|---|
| Ползунок «Минимальное значение для типовой реакции, г» | поле фильтрации, от 0 до самого большого значения в коллекции |
| Подпись под заголовком | «Показаны все материалы» либо «Показаны материалы от N г» |
| Шкала ползунка | нижняя и верхняя границы диапазона |
| Тег «Найдено: N» | сколько материалов показано после фильтрации |
| Карточка материала | изображение, бейдж с минимальной массой, название, количество лайков |

| Кнопка | Действие |
|---|---|
| Применить | фильтрует список по текущему положению ползунка |
| Сбросить | возвращает ползунок в 0 и показывает все материалы |
| Нажатие на карточку | открывает страницу «Подробнее» для выбранного материала |

Пока ползунок двигают, список не меняется — он перестраивается только
по кнопке «Применить».

### Лента — `/feed`

Один материал поверх проигрываемого короткого видео. Открывается с первого
материала коллекции.

| Элемент | Что это |
|---|---|
| Видео на весь экран | короткое видео материала, проигрывается по кругу без звука |
| Карточка-оверлей | название материала и краткое описание |
| Чип «Мин. для реакции, г» | минимальная масса вещества для типовой реакции |
| Чип «Молярная масса, г/моль» | молярная масса вещества |
| Иконка лайка | количество лайков материала |

| Кнопка | Действие |
|---|---|
| Больше / Меньше | разворачивает и сворачивает краткое описание |
| Далее | показывает следующий материал; за последним лента возвращается к первому |

### Подробнее — `/feed/:id`

Тот же материал, но открытый по идентификатору — сюда переходят нажатием
на карточку плитки. Набор полей и кнопок совпадает с лентой, отличие
в поведении «Далее»: здесь меняется адрес страницы, поэтому работают
кнопки «назад» и «вперёд» браузера.

### Навигационная панель

Закреплена снизу на всех страницах, состоит из четырёх пунктов.

| Пункт | Адрес | Доступен |
|---|---|---|
| Лента | `/feed` | да |
| Добавление | `/draft` | нет — появится после подключения веб-сервиса |
| Плитка | `/` | да |
| Вход | `/login` | нет — появится после подключения веб-сервиса |

Недоступные пункты показаны приглушённо и не нажимаются. Активный пункт
подсвечивается по текущему адресу: материал, открытый из плитки, подсвечивает
«Ленту», потому что его адрес начинается с `/feed`.

Иконки нарисованы в `src/components/TabBarIcons.tsx` как SVG, а не подключены
картинками: цвет берётся из `currentColor`, поэтому выбранный пункт синий,
остальные приглушённые, и фигура остаётся чёткой на любом экране. У активного
пункта фигура залита, у остальных нарисована контуром.

## Изображение и видео по умолчанию

Веб-сервис хранит только имя файла, поэтому адрес собирает фронтенд —
`src/modules/media.ts`. Если имя пустое, подставляется файл по умолчанию
из папки `public`, который попадает в сборку вместе с приложением:

- `public/default_material.png` — изображение,
- `public/default_material.mp4` — видео.

В коллекции mock-объектов у материала «Катализатор Ni/Al₂O₃» оба имени
пустые — на нём видно подстановку и изображения в плитке, и видео в ленте.
Так же выглядит только что созданный материал, которому ещё не загрузили
медиа. У остальных четырёх материалов медиа свои, они лежат
в `public/materials`.

Дополнительно у тега `<img>` стоит обработчик `onError`: если файл
с таким именем не открылся, картинка переключается на изображение
по умолчанию. Обработчик снимает сам себя, чтобы не зациклиться.
У видео ту же роль играет второй тег `<source>` с роликом по умолчанию:
если первый файл не открылся, браузер сам переходит к следующему.

## Компоненты и props

Страницы хранят состояние, компоненты только отображают то, что получили,
и сообщают наверх о действиях пользователя. Ни один компонент не обращается
к коллекции mock-объектов напрямую.

`MaterialFilter` — управляемый компонент без собственного состояния:

| Props | Назначение |
|---|---|
| `value` | текущее положение ползунка |
| `appliedValue` | значение, по которому список отфильтрован сейчас |
| `maxValue` | верхняя граница ползунка |
| `foundCount` | сколько материалов показано |
| `onChange` | ползунок сдвинули |
| `onApply` | нажали «Применить» |
| `onReset` | нажали «Сбросить» |

Значение ползунка и применённое значение разделены и оба лежат в состоянии
страницы `CatalogPage`. Благодаря этому фильтр ничего не знает ни о списке
материалов, ни о странице, на которой стоит.

`MaterialCard` получает поля одного материала и обработчик `onOpen`, которому
передаёт идентификатор при нажатии. `FeedMaterial` получает материал целиком
и обработчик `onNext`; собственное состояние у него одно — развёрнуто ли
описание.

## Хуки

| Хук | Где используется | Зачем |
|---|---|---|
| `useState` | все три страницы, `FeedMaterial` | список материалов, состояние загрузки, положение и применённое значение фильтра, текущий материал ленты, развёрнутость описания |
| `useEffect` | `CatalogPage`, `FeedPage`, `MaterialPage` | получение данных после отрисовки страницы и при смене зависимостей |
| `useParams` | `MaterialPage` | идентификатор материала из адреса страницы |
| `useNavigate` | `CatalogPage`, `MaterialPage` | переход на страницу материала и к следующему материалу |
| `useLocation` | `TabBar` | подсветка активного пункта по текущему адресу |

Эффекты получения данных написаны с уборкой. Внутри заводится флаг `actual`,
а возвращаемая из эффекта функция сбрасывает его. Если страницу закрыли или
зависимость сменилась до прихода ответа, результат прошлого вызова
отбрасывается и состояние не обновляется.

Все функции получения данных асинхронные, хотя данные лежат в коллекции
mock-объектов. Сделано это намеренно: страницы обращаются к ним так же,
как будут обращаться к веб-сервису, поэтому при подключении бэкенда меняются
только тела функций в `src/modules/materialsApi.ts`.
